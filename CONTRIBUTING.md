# Как дополнить каталог преподавателей

Общий студенческий каталог: https://smit1980.github.io/DPO-1_course/

Репозиторий каталога: https://github.com/Smit1980/DPO-1_course

1. Добавьте HTML-конспект в `web/`, DOCX/MD в `Docs/`. Не перезаписывайте существующие конспекты.
2. В `index.html` скопируйте `<div class="lesson fade">` внутри секции `konspekty`, задайте уникальный `id`, название, описание и ссылки.
3. Если конспект находится в репозитории урока, добавьте проверенную абсолютную ссылку. Дублировать файл необязательно.
4. Если отдельного конспекта нет, укажите «Лекционный материал» или «Сценарий встроен», не называйте страницу отдельным преподавательским конспектом.
5. Проверьте ссылки, скачивание и мобильный вид. Создайте pull request. GitHub Pages: `main`, `/`, без отдельной сборки.

Публичный репозиторий не даёт посетителю права записи: нужен Collaborator-доступ от владельца либо fork и pull request. Права на репозитории ElenaChepik назначает их владелец.

## Можно добавить

- Отдельные конспекты двух лекций Елены Чепик по промптам.
- Отдельный конспект мультимодальной второй пары.
- Согласованную новую версию рабочих сценариев вместо сохранённого черновика урока 8.

Преподавательские ключи не размещайте на главной странице слушателей. Не публикуйте анкеты, договоры, внутренние документы, пароли или ключи.
